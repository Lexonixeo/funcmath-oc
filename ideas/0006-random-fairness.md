# 0006. Честность и вероятность в случайных уровнях

**Статус:** идея
**Сложность:** средняя

## Суть

Сейчас случайные уровни (`rand`, `sumr`, `subr`, `mulr`, `divr`) считаются
решаемыми, если цель достижима **хотя бы при одном** исходе. Игроку это может
стоить десятков попыток, а подсказка лишь предупреждает: «результат случайный».

Предлагается сделать случайность честнее и информативнее:

1. **Вероятность успеха.** Для найденного плана считать произведение
   вероятностей исходов и показывать в `hint`:
   `(шанс успеха ≈ 1/31 за попытку)`.
2. **Детерминированный seed.** Команда `seed N` (или seed уровня) делает `rand`
   воспроизводимым. Тогда игрок может переигрывать один и тот же сценарий,
   а не полагаться на удачу.
3. **Явный диапазон.** В описании `rand` показывать, какие числа возможны:
   `rand(a, b)` → `[min(a,b); max(a,b)]`.
4. **Ожидаемое число попыток.** Для плана с вероятностью `p` показывать
   `в среднем 1/p попыток`.
5. **Мягкий режим.** Флаг «случайность с запасом»: уровень считается
   пройденным, если цель достигнута при любом исходе (строгий режим) или
   хотя бы при одном (текущий). Это можно сделать настройкой сложности.

## Зачем

- Случайные уровни перестают быть лотереей без информации.
- Появляется образовательный элемент: вероятность, ожидание, дерево исходов.
- Легче тестировать уровни: с seed они воспроизводимы.

## Эскиз реализации

- `fmath::outcomes` уже возвращает все исходы; добавить к каждому вероятность
  (для `rand` — равномерно, для `*r` — по распределению погрешности).
- В `Solver` хранить вероятность пути; при нахождении решения возвращать
  `prob`.
- `rand` заменить на детерминированный PRNG (например, `std::mt19937`),
  seed хранить в состоянии уровня.
- В `Level` добавить команду `seed` и вывод вероятности в `hint`.

## Риски

- Вероятности для `sumr/subr/mulr/divr` нужно определить явно; сейчас это
  «базовое значение ± константа», и распределение не задано.
- Нельзя ломать существующие уровни: по умолчанию поведение должно остаться
  прежним, новые возможности — по флагу/команде.
