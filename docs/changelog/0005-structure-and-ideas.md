# 0005. Рефакторинг структуры и идеи из письма

**Дата:** 2026-10-19

## Что сделано

### Удалён первый прототип

- Удалены `funcmath.cpp` и `funcmath_linux.cpp` — ранний однофайловый
  прототип, который больше не является частью рабочей версии.
- Удалены старые бинарники `funcmath.exe` и `funcmath_linux.exe`.
- При необходимости старый код можно достать из истории git (он был в
  коммите `1ca840a` и раньше).

### Рефакторинг папок и структуры хранения

Было:

```
funcmath-cpp/
  src/ data/ CMakeLists.txt build.bat README.md .gitignore
changelog/
ideas/
funcmath.cpp, funcmath_linux.cpp
```

Стало — единый проект в корне:

```
src/                 исходники
data/                функции и уровни
  levels/            62 уровня
  players/           сохранения (создаются при игре)
docs/
  game.md            подробная документация
  changelog/         история изменений
  ideas/             идеи на будущее
CMakeLists.txt
build.bat
README.md
```

- Убрана вложенность `funcmath-cpp/`; сборка снова идёт из корня.
- Документация перенесена в `docs/`, чтобы не смешиваться с кодом.
- Дублирующий `funcmath-cpp/.gitignore` удалён; корневой `.gitignore`
  обновлён (`data/players/`, `data/lvlrate.dat`, `data/cache/`).
- `build.bat` переведён на CRLF и UTF-8 (`chcp 65001`), чтобы русские
  сообщения отображались корректно.
- `.vscode/settings.json` (не в git) указывает CMake на корень проекта.

### Новые идеи

В `docs/ideas/` добавлены:

- **0007** — кэш решателя: сначала готовые шаги, при неудаче — DFS;
- **0008** — браузерный интерфейс в духе nandgame;
- **0009** — векторы, строки и предметы вместо только чисел;
- **0010** — сложность уровня и генерация под заданную сложность;
- **0011** — мультиплеер: кооператив и гонка;
- **0012** — редактор уровней и обмен ими.

Идеи 0008–0011 взяты из письма руководителю проекта; 0007 предложена
пользователем; 0012 — производная от браузерного UI и генерации.

## Зачем

- В репозитории осталась одна актуальная версия, без путаницы между
  «первым прототипом» и основной игрой.
- Плоская структура упрощает сборку, запуск и навигацию.
- Идеи из письма зафиксированы в репозитории, а не только в переписке.
