# 0001. Отдельный репозиторий и README

**Дата:** 2026-10-19
**Коммит:** `1ca840a` — «func(math): первая версия проекта»

## Что сделано

- Создан отдельный git-репозиторий для всей папки `opencode/funcmath`.
  Раньше в корне лежал репозиторий старого прототипа `funcmathcpp1`
  (remote — `github.com/Lexonixeo/funcmathcpp1`); его локальный `.git` перемещён
  в резервную копию вне проекта, чтобы не потерять историю.
- Добавлены корневые файлы:
  - `README.md` — смысл игры, структура папки, быстрый старт, планы;
  - `.gitignore` — исключены `*.exe`, сборки и данные игроков;
  - `.gitattributes` — нормализация переводов строк (LF в репозитории).
- Первый коммит включил всю папку: основную версию `funcmath-cpp/`
  (85 файлов, включая 56 уровней) и ранний однофайловый прототип `funcmath.cpp`.

## Почему

Пользователь попросил отдельный репозиторий всей папки и не мог найти `README.md`:
он лежал только внутри `funcmath-cpp/`, а в корне его не было.
