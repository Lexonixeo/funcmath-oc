# func(math) — C++17

Порт консольной игры **func(math)** с Java (`github.com/Lexonixeo/funcmathjava1`) на C++17.
Геймплей сохранён, но проект переписан и разбит на модули, а данные уровней переведены
из Java-сериализации (`*.dat`) в читаемый текстовый формат (`*.lvl`).

Это подробная документация. Краткий обзор и структура репозитория — в
[`../README.md`](../README.md).

## Возможности

- 78 уровней: 40 оригинальных, 16 новых (41–56), 6 из раннего прототипа
  (57–62) и 16 из Java-прототипа (63–78).
- Типы значений `natural` и `integer` (у каждого числа свой тип).
- 23 функции: арифметика, побитовые операции, конкатенация, системы счисления,
  разложение на простые множители и др.
- Функции произвольной арности и с несколькими результатами; вложенные
  префиксные выражения.
- «Неизвестные» функции: игрок видит имя, но не знает поведение.
- История ходов (`history`) и показ текущего набора после каждого хода.
- Аккаунты, сохранения, статистика, оценки сложности уровней.
- Подсказка (`hint`) на основе встроенного решателя.
- Генератор случайных уровней и режим создания уровней (`--author`).
- Проверка решаемости всех уровней (`--check`).

## Отличия от Java-версии

- Полностью переписан на C++17, без внешних зависимостей.
- Исходники разбиты по файлам (см. «Структура»).
- Уровни хранятся в текстовых `data/levels/levelN.lvl` вместо `*.dat`.
- Доработаны бывшие заглушками функции: `random`, `stats`, `hint`.
- Добавлены режимы `--check` и `--author`.
- Объединён с ранним C++-прототипом: добавлены `history`, показ остатка набора
  после хода, `cls` и 6 уровней со скрытыми функциями `five`/`neg2`.
- Исправлен `last`: в Java он открывал текущий уровень заново, хотя подсказка
  обещает предыдущий.
- Арифметика на 64-битных значениях с насыщением на ±1e18 и делением на ноль → 0
  (в Java использовались `Integer.MAX_VALUE/MIN_VALUE`, что давало переполнения и UB).
  `natural` не может быть отрицательным: вычитание большего из меньшего — ошибка.
- Исправлено зацикливание ввода при неверном пароле и EOF.
- `chcp`/`cls` больше не запускают `cmd.exe` (иначе «съедался» перенаправленный stdin).

| `data/functions.txt` | описания функций |

## Сборка

Через g++ (MinGW / Linux):

```sh
g++ -std=c++17 -Wall -Wextra -O2 -o funcmath \
    src/Helper.cpp src/Functions.cpp src/Function.cpp src/LevelStore.cpp \
    src/Level.cpp src/Solver.cpp src/LevelGenerator.cpp src/Player.cpp \
    src/Game.cpp src/main.cpp
```

Через CMake:

```sh
cmake -S . -B build
cmake --build build
```

Каталог `data/` копируется рядом с бинарником автоматически (CMake).
Для Windows есть `build.bat`.

Игру нужно запускать из каталога, где находится `data/`
(или из `build/`, если CMake скопировал данные).

## Запуск

```sh
funcmath            # игра
funcmath --check    # проверить все уровни на решаемость
funcmath --check 18 --nodes 5000000 --time 10000
funcmath --author   # создать новый уровень
```

### Команды главного меню

| Команда | Действие |
|---------|----------|
| `play` | продолжить с первого непройденного уровня |
| `level N` | открыть уровень N |
| `random D` | случайный уровень сложности D |
| `last` / `next` | предыдущий / следующий уровень |
| `stats` | статистика игрока |
| `help` | список команд |
| `exit` | выход |

### Команды внутри уровня

| Команда | Действие |
|---------|----------|
| `func a b` | применить функцию к числам `a` и `b` |
| `calc func a b` | посчитать, не изменяя набор |
| `nums` | показать текущий набор чисел |
| `history` | показать историю ходов |
| `hint` | подсказать ход (best-effort) |
| `back` | отменить последний ход |
| `reset` | начать уровень заново |
| `clear` / `cls` | очистить экран |
| `help` | справка |
| `exit` | выйти из уровня |

Запись выражения: `func a b`, без скобок и запятых (например `sum 1 3`).
Запятые и скобки считаются разделителями, поэтому `sum(1,2)` тоже работает.
Применив функцию, вы забираете два числа из набора и добавляете результат.

## Формат уровня `.lvl`

Новый формат с типами:

```
# комментарий
number natural 3
number natural 4
number natural 5
answer natural 12
function sum
function A unknown mul
```

Старый формат без типов тоже поддерживается: все числа и ответ считаются
`integer`.

```
numbers 1 2 34
answer 1234
function conc
```

- `number <тип> <значение>` — одно число набора; тип `natural` или `integer`;
- `numbers ...` — старый компактный формат, все числа `integer`;
- `answer [<тип>] <значение>` — целевое число;
- `function <имя>` — известная функция;
- `function <имя> unknown <поведение>` — функция со скрытым поведением:
  игрок видит только имя, а работает она как `<поведение>`.

`natural` — неотрицательный тип: отрицательные значения в файле запрещены, а
операции, дающие отрицательный результат, считаются ошибкой. `integer` —
обычный знаковый 64-битный тип. Старые уровни остаются `integer`; новые
уровни прототипа используют `natural` там, где это уместно.

## Функции

```
sum  sub  mul  div  mod  abs  pow  rand
and  or   not  xor  avg  conc base round
sumr subr mulr divr
primes
five neg2
```

`sumr/subr/mulr/divr` — версии с погрешностью, `rand` — случайная.
`primes` — унарная функция: возвращает простые множители числа (может вернуть
несколько результатов). `five` (всегда 5) и `neg2` (`-a + 2`) — поведения из
раннего прототипа; они нужны для уровней 57–62 и не попадают в генератор
случайных уровней. Старые функции `abs`/`not` пока остаются бинарными: второй
аргумент игнорируется, чтобы не ломать уровни 23, 44 и 57.

Решатель работает и со случайными функциями: он перебирает все возможные
исходы, поэтому найденное решение означает «достижимо при удачном исходе».

## Выражения и арность

Выражения записываются в префиксной форме без скобок и запятых. Функция сама
знает, сколько аргументов ей нужно; аргументом может быть число из набора или
другое выражение:

```
sum 1 3
sum 1 sum 2 3
mul 3 mul 7 11
primes 30
```

При выполнении выражения из набора удаляются все числа-листья, а в набор
добавляются результаты корневой функции. Вложенное выражение эквивалентно
последовательности обычных ходов, но записывается одной строкой. `calc`
разбирает такое же выражение, не меняя набор.

Если функция возвращает несколько результатов (`primes`), все они добавляются
в набор. Внутреннее выражение с несколькими результатами может заполнить
несколько аргументов родительской функции; например, `mul primes 77` — это
`mul 7 11`.

## Уровни

- **1–40** — из оригинальной Java-версии (формат переведён из `*.dat`).
- **41–56** — новые: побитовые операции (`and`/`or`/`xor`/`not`), `conc`, `base`
  и уровни с «неизвестными» функциями.
- **57–62** — из раннего однофайлового прототипа: скрытые функции `A`/`B`
  с поведениями `five` и `neg2`. Уровень 60 в прототипе был нерешаемым
  (цель 15), поэтому его цель заменена на достижимую `-25`.
- **63–78** — 16 уровней Java-прототипа: первые 13 на `natural`, последние
  3 на `integer`. Названия и авторские подсказки сохранены в
  `docs/prototype/levels.md`; в игре `hint` пока вычисляется решателем.
  Уровень 68 («Слепота») содержит 142 числа и проверяет устойчивость
  решателя к большим мультимножествам.

## Особенности и ограничения

- `hint` — эвристика: для особо сложных уровней может не найти решение за лимит.
- Случайные функции (`rand`, `sumr`, …) решатель перебирает полностью: уровень
  считается решаемым, если цель достижима при каком-то исходе. Для игрока это
  значит «нужна удача/несколько попыток», и `hint` об этом предупреждает.
  Вся стратегия перебора собрана в `fmath::outcomes` (`src/Functions.cpp`) —
  её легко заменить, не трогая решатель.
- Уровень 18 (найти `2048` из `1..14,35,99,105,117` через `div`/`mul`) решаем,
  но обычный DFS находит его не сразу. Решение вручную:
  `mul 6 12=72; div 72 9=8; div 10 5=2; div 14 7=2; mul 2 4=8;`
  `mul 8 8=64; mul 64 2=128; mul 128 2=256; mul 256 8=2048`.
- Уровень 32 решается благодаря целочисленному (усекающему) `avg`.
- `round` для целых чисел не меняет значение (все числа уже целые).
