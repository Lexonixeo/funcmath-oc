# 0002. Полный перебор случайности в решателе

**Дата:** 2026-10-19

## Что сделано

- Добавлена `fmath::outcomes(name, a, b)` — список возможных результатов функции:
  - `rand(a, b)` — весь диапазон `[min(a,b), max(a,b)]`;
  - `sumr / subr` — базовое значение ± 10;
  - `mulr / divr` — базовое значение ± 25;
  - стабильные функции — один результат.
- Решатель (`src/Solver.cpp`) больше не пропускает случайные функции: он
  перебирает все возможные исходы. Решение считается найденным, если оно
  достижимо хотя бы при одном исходе случайности.
- `--check` теперь проверяет и случайные уровни, помечая их
  «(случайные функции)».
- `hint` больше не отказывает на случайных уровнях; он предупреждает, что
  результат случайный и может понадобиться несколько попыток.
- Стартовые лимиты решателя подняты до 200 000 узлов / 1000 мс.

## Зачем

Раньше уровни 33, 34, 37, 38, 39, 40 (`rand`, `sumr`, `subr`, `mulr`) при
проверке просто пропускались, а подсказка была недоступна. Пользователь
предложил перебирать случайность полностью, пока числа в уровнях малы.

## Результат

```
funcmath --check
Итого: решаемо 55, не найдено 1, со случайностью 6, с ошибками 0.
```

Единственный не найденный — уровень 18: он решаем (решение вручную есть в
README), но обычный DFS не успевает за лимит. Все шесть случайных уровней
найдены за доли секунды.

## Как переделать в будущем

Вся стратегия перебора собрана в одном месте: `kMaxOutcomes` и `outcomes()`
в `funcmath-cpp/src/Functions.cpp`. Решатель лишь вызывает `outcomes()`, поэтому
достаточно заменить эту функцию (например, на сэмплирование или вероятностную
модель), не трогая поиск.
