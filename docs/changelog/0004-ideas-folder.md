# 0004. Папка идей на будущее

**Дата:** 2026-10-19

## Что сделано

Создана папка `ideas/` для идей, которые пока не реализованы. В ней:

- `README.md` — зачем папка, формат заметок и таблица идей;
- `0001-history-tree.md` — история ходов в виде дерева (идея пользователя);
- `0002-number-theory.md` — функции и уровни в духе №19 ЕГЭ;
- `0003-shortest-solution.md` — кратчайшее решение для `hint` и `--check`;
- `0004-level-validation.md` — проверка и линт уровней;
- `0005-progress-and-ui.md` — прогресс, достижения и сохранение партии;
- `0006-random-fairness.md` — честность и вероятность в случайных уровнях.

У каждой заметки есть суть, польза, эскиз реализации, сложность и список
затрагиваемых файлов.

## Зачем

Пользователь попросил папку для идей «на будущее» и привёл пример: история
ходов в виде дерева. Идеи удобнее хранить в репозитории, чем в переписке:
их можно уточнять, оценивать и постепенно реализовывать.

## Результат

Код игры не менялся — это только документация. Основная версия остаётся
в состоянии после коммита `2c44d55` (62 уровня, слияние прототипов).
Следующая крупная доработка — «усложнённый» прототип, который пользователь
предоставит отдельно.
