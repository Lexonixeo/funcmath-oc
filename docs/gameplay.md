# func(math): полное руководство игрока

Это практическое руководство по игре: как запускать, как читать уровень, как
писать выражения и как не запутаться в типах, функциях и потоках результатов.
Краткая справка внутри уровня намеренно короткая; этот файл — для подробного
разбора.

## 1. Что происходит в игре

В каждом уровне есть:

- набор чисел;
- набор доступных функций;
- цель — получить определённое число.

Функция забирает из набора свои аргументы и добавляет в набор результаты.
Если после хода цель оказалась в наборе, уровень пройден.

Например, в наборе есть `1` и `3`, а функция `sum` складывает два числа:

```text
sum 1 3
```

После хода `1` и `3` исчезают из набора, а вместо них появляется `4`.

## 2. Запуск

### Готовая сборка

Релизы публикуются как архивы вида:

```text
funcmath-ds-v0.2.0-windows-x64.zip
funcmath-ds-v0.2.0-linux-x64.tar.gz
funcmath-ds-v0.2.0-macos-arm64.tar.gz
```

Внутри архива рядом с исполняемым файлом должна лежать папка `data/`. Игру
нужно запускать из каталога, где эта папка видна, либо из корня распакованного
архива.

- Windows: `funcmath.exe`
- Linux/macOS: `./funcmath`

### Сборка из исходников

Нужны:

- компилятор C++17;
- CMake 3.16+ (рекомендуется более новый);
- терминал с поддержкой UTF-8.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
./build/funcmath
```

На Windows с MSVC исполняемый файл обычно оказывается в
`build/Release/funcmath.exe`.

Также можно собрать одним файлом через `build.bat` или командой `g++` из
[README](../README.md).

### Требования к системе

- Windows 10/11 x64;
- Linux x64 с glibc 2.35+ (например, Ubuntu 22.04+);
- macOS 12+ arm64;
- терминал с моноширинным шрифтом и поддержкой UTF-8;
- отдельного GUI, браузера или интернета не требуется.

Точные версии и состав конкретного релиза смотрите в описании релиза на
GitHub.

## 3. Главное меню

| Команда | Действие |
|---------|----------|
| `play` | продолжить с первого непройденного уровня |
| `level N` | открыть уровень `N` |
| `random D` | сгенерировать случайный уровень сложности `D` |
| `next` / `last` | следующий / предыдущий уровень |
| `stats` | статистика игрока |
| `menu` | перерисовать главное меню |
| `help` | список команд |
| `exit` | выйти из игры |

## 4. Команды внутри уровня

| Команда | Действие |
|---------|----------|
| `выражение` | сделать ход |
| `calc выражение` | вычислить, не меняя набор |
| `nums` | показать текущий набор |
| `history` | показать историю ходов |
| `hint` | подсказать ход (если решатель смог найти) |
| `back` | отменить последний ход |
| `reset` | вернуть набор к начальному состоянию |
| `clear` / `cls` | очистить экран |
| `help` | краткая справка |
| `exit` | выйти из уровня |

`calc` — главный инструмент исследования. Он разбирает выражение по тем же
правилам, что и обычный ход, но не забирает числа из набора и не добавляет
результаты.

## 5. Числа и типы

У каждого числа есть тип:

- `natural` — неотрицательное целое;
- `integer` — целое, включая отрицательные.

Тип хранится у конкретного числа, а не у всего набора. В одном наборе могут
быть `2(natural)` и `2(integer)` — это разные числа.

### Обычные числа

В наборе число может быть записано просто как значение:

```text
number natural 3
number natural 4
```

При вводе имя функции и число разделяются пробелами:

```text
sum 3 4
```

### Типизированные литералы

Если тип неоднозначен, используйте явную форму:

```text
natural=2
integer=2
```

Отрицательный типизированный литерал пишется так:

```text
integer=-3
```

Не `integer(-3)` и не `-integer=3`.

В обычном ходе типизированный литерал должен соответствовать числу из набора.
В `calc` он создаёт значение нужного типа, даже если такого числа в наборе нет;
поэтому `calc` удобен для проверки гипотез.

### Имена чисел

Числу можно дать метку:

```text
number natural 3 as x
```

Тогда `x` можно использовать вместо значения:

```text
mul x x
```

Имя — это удобная ссылка, а не отдельное «бесконечное» число. После
использования имя исчезает вместе с числом. У результатов вычислений имён нет.

### Одинаковые числа

Если в наборе несколько одинаковых чисел, при вводе голого значения игра
выбирает подходящий экземпляр. Если одинаковых чисел разных типов несколько,
нужен `natural=2` или `integer=2`.

### Расход чисел

Обычный ход забирает из набора все числа-аргументы. Поэтому, если одно и то же
значение нужно дважды, в наборе должно быть два экземпляра или два имени.

`calc` ничего не забирает: он читает набор, но не меняет его.

## 6. Выражения

Есть две равноправные записи. Внутри одного выражения их нельзя смешивать.

### 6.1. Префиксная запись

Функция стоит первой, затем её аргументы:

```text
sum 1 3
sum 1 sum 2 3
mul 3 mul 7 11
primes 30
```

Функция сама знает, сколько аргументов ей нужно. Аргумент может быть числом,
именем, литералом или другим выражением.

Префиксная запись — основная для потоков и нескольких результатов. Например,
`primes 30` возвращает поток `2 3 5`.

### 6.2. Инфиксная запись

Для привычной математики можно писать операторы:

```text
1 + 3
(1 + 2) * 3
2 ** 10
sum(1, 3) + 4
mul(3, 7) + 11
```

Соответствие операторов:

| Оператор | Функция |
|----------|---------|
| `+` | `sum` |
| `-` | `sub` |
| `*` | `mul` |
| `/` | `div` |
| `%` | `mod` |
| `**` | `pow` |

Важно: оператор — это только синтаксический сахар. Если в уровне нет функции
`sum`, то запись `1 + 2` не сработает. Игра не добавляет функции, которых нет
в уровне.

Приоритеты:

1. `**` — самый высокий, правоассоциативный:
   `2 ** 3 ** 2` означает `2 ** (3 ** 2)`;
2. `*`, `/`, `%`;
3. `+`, `-`.

Скобки меняют порядок:

```text
1 + 2 * 3     -> 7
(1 + 2) * 3   -> 9
```

### 6.3. Вызовы функций в инфиксе

Функция вызывается с аргументами через запятую:

```text
sum(1, 2)
f(1 + 2, 3)
mul(2, sum(3, 4))
```

Если функция принимает один аргумент, всё равно нужны скобки:

```text
primes(30)
```

### 6.4. Унарный минус

Унарный минус разрешён только перед числовым литералом:

```text
-3
1 - -2
```

Для типизированного литерала знак пишется внутри:

```text
integer=-3
```

Отрицание произвольного выражения, например `-(1 + 2)`, пока не поддерживается.

### 6.5. Что нельзя смешивать

Нельзя смешивать в одном выражении старый префиксный вызов и инфикс:

```text
sum 1 2 + 3      # ошибка
sum(1, 2) + 3    # правильно
```

Также нельзя писать `^` вместо степени. Используйте `**` или `pow`.

### 6.6. Совместимость со старыми выражениями

Старые префиксные формы продолжают работать:

```text
sum 1 2
sum 1 -2
sum(1,2)
```

`sum 1 -2` — это старый префиксный вызов с отрицательным литералом. Если нужен
именно двоичный минус, пишите `sum 1 2 - 3` или `sum(1, 2) - 3`.

## 7. Функции

### 7.1. Три вида функций

- **Известная** — её поведение написано в описании уровня: `sum`, `mul`,
  `primes`.
- **Неизвестная** — имя есть, поведение скрыто; его нужно выяснить через
  `calc`.
- **Пользовательская** — задана блоком `function ... end` в уровне или файле
  `.fn`.

### 7.2. Арность и результаты

Функция может:

- принимать один или несколько аргументов;
- возвращать один результат;
- возвращать несколько результатов;
- возвращать поток результатов.

Поток — это последовательность значений, которую можно обрабатывать
постепенно. В текущей версии поддерживается один поток, и он должен быть
последним результатом.

### 7.3. Работа с потоком

В телах пользовательских функций доступны специальные префиксные формы:

| Форма | Смысл |
|-------|-------|
| `first expr` | первый результат |
| `rest expr` | все результаты, кроме первого |
| `take n expr` | ровно первые `n` результатов |
| `drop n expr` | остаток после первых `n` |
| `count expr` | количество результатов |

В обычном уровне этих форм нет: там можно вызывать только функции, выданные
уровнем. Внутри тела функции их можно комбинировать с инфиксной записью,
например `count(primes(30))`.

### 7.4. Пользовательские функции

Пользовательская функция описывается блоком:

```text
function double
  in x: natural
  out r: natural
  body
    r = x + x
end
```

В теле можно использовать:

- параметры;
- локальные переменные;
- выходы;
- встроенные функции;
- другие пользовательские функции;
- инфиксную запись.

Тело — это последовательность присваиваний. Каждое имя вычисляется один раз и
доступно следующим строкам. Несколько результатов можно принять сразу:

```text
q, r = divmod a b
```

### 7.5. Случайность

Функция `rand` возвращает случайное число. Уровни с `rand` могут иметь
несколько допустимых исходов. Решатель перебирает их, но подсказка может быть
осторожной: один и тот же ход не всегда гарантирует результат.

В текущей версии цель проверяется точно. В будущем случайность может
моделировать физические величины с погрешностью, а ответ — проверяться в
допуске; это пока идея, а не реализованная механика.

## 8. Ошибки и безопасность хода

Ошибка в выражении не должна портить набор. Если разбор или вычисление не
удались, набор остаётся прежним, а игра печатает сообщение.

Типичные ошибки:

- неизвестная функция;
- не хватает аргументов;
- лишние аргументы;
- число не подходит по типу;
- отрицательный `natural`;
- деление на ноль (в текущей реализации `div` возвращает `0`, как в исходном
  Java-прототипе);
- незакрытая скобка или лишняя запятая.

Если ошибка непонятна, попробуйте разбить выражение на части через `calc`.

## 9. Как решать уровни

1. Посмотрите на цель и набор чисел.
2. Выпишите, какие функции доступны.
3. Попробуйте получить промежуточные значения через `calc`.
4. Если есть имена, используйте их для повторного употребления числа.
5. Если есть поток, подумайте, какие его элементы нужны.
6. Если решение «почти получилось», проверьте типы: возможно, нужен
   `natural=...` или `integer=...`.
7. Если застряли, `hint` может предложить ход, но не гарантирует короткий путь.

Полезная привычка: сначала найти путь в обратную сторону — от ответа к
исходным числам.

## 10. Частые вопросы

### Почему `1 + 2` не работает в моём уровне?

Потому что `+` вызывает `sum`, а этой функции может не быть в уровне. Проверьте
список функций.

### Почему `sum 1 -2` работает, а `sum 1 - 2` — нет?

`sum 1 -2` — старый префиксный вызов с отрицательным литералом. `sum 1 - 2`
смешивает префикс и инфикс, поэтому игра требует записать это как
`sum(1, 2) - 3` или `sum 1 2 - 3` (если доступен `sub`).

### Почему нельзя написать `integer(-3)`?

Потому что типизированный литерал — это часть синтаксиса числа:
`integer=-3`. Скобки после `integer` означали бы вызов функции с именем
`integer`.

### Почему `2 ** 3` иногда не работает?

Нужна функция `pow` в уровне. `**` — просто её инфиксная запись.
