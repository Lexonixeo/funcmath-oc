# 0018. Обучение функциональному программированию

**Статус:** идея
**Сложность:** средняя

## Суть

Игра уже похожа на маленький функциональный язык: чистые функции,
иммутабельные связывания, потоки, перегрузки, поиск по состоянию. Можно
сделать образовательный трек, который параллельно с №19 ЕГЭ объясняет идеи
Haskell/ФЯП.

## Что можно преподавать

- чистые функции и отсутствие побочных эффектов;
- рекурсию и свёртки (`fold`);
- списки и потоки (`primes`, `take`, `drop`);
- `map`/`filter`/`fold` на примерах уровней;
- алгебраические типы и сопоставление с образцом;
- перегрузки как type classes;
- ленивость и `if` как специальную форму;
- случайность как эффект;
- монады — позже, на примере состояния набора и `Maybe`/`Either`.

## Формат

- отдельные уровни-«теории» с карточками и примерами;
- подсказки со ссылками на концепции (идея 0013);
- катсцены/диалоги (идея 0014);
- режим «Haskell-трек»: те же функции, но с показом аналогов на Haskell;
- упражнения: «перепиши это выражение через `fold`», «свёртка versus рекурсия».

## Примеры соответствий

| Игра | ФЯП |
|---|---|
| `sum a b` | бинарная функция |
| `primes n` | многозначная функция / список |
| `take 2 xs` | `take 2 xs` |
| `body` с `=` | `let ... in` |
| перегрузки `sum` | type class / ad-hoc полиморфизм |
| `rand` | эффект/недетерминизм |
| решатель | поиск по пространству состояний |

## Риски

- не превратить игру в учебник;
- не отпугнуть игроков, которым нужен только геймплей;
- теория должна быть необязательной.
