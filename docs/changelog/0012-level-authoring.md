# 0012. Уровень 79 и руководство по `.lvl`

**Дата:** 2026-10-21

## Что сделано

- Добавлен уровень `data/levels/level79.lvl`: именованное число `n=84`,
  пользовательская функция `split` с фиксированным выходом и потоком,
  typed-литерал `natural=2`, цель `42`.
- Добавлено руководство `docs/level-authoring.md`: создание `.lvl` в Блокноте,
  кодировка UTF-8 без BOM, числа и типы, имена, пользовательские функции,
  потоки, `use`-алиасы, `.fn`, проверка через `--check` и типичные ошибки.
- Руководство связано с `README.md` и `docs/game.md`.

## Зачем

Уровень 79 показывает новые механики в небольшой учебной задаче, а руководство
позволяет писать и проверять уровни без чтения исходников парсера.

## Проверки

- `funcmath --check 79` — уровень решаем за 3 хода.
- Уровень 79 пройден вручную: `split n`, `mul 3 7`, `double 21`.
- Примеры `divmod`, `use`-алиаса и шаблона из руководства проверены временными
  уровнями; после проверки они удалены.
