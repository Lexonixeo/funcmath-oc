# 0012. Редактор уровней и обмен ими

**Статус:** идея
**Сложность:** средне-высокая

## Суть

Браузерный редактор уровней: расставить числа, выбрать функции, задать цель,
проверить решаемость, посчитать сложность и поделиться уровнем по ссылке/коду.
Это естественное дополнение к браузерному UI (0008) и генерации (0010).

## Возможности

- Форма уровня: набор чисел, цель, функции, скрытые поведения.
- Предпросмотр: «пройти уровень» прямо в редакторе.
- Проверка (идея 0004): решаем ли уровень, нет ли тривиального решения,
  нет ли цели в стартовом наборе.
- Оценка сложности (идея 0010): минимальное число ходов, branching, метрики.
- Экспорт/импорт:
  - `.lvl` — совместимость с консольной версией;
  - JSON — для браузера и обмена;
  - короткий код уровня (base64/сжатие) для ссылки.
- Публикация: галерея уровней, теги, рейтинги, репорты.
- Версии уровня: автор может обновить, старые решения/кэш инвалидируются.

## Зачем

- Игроки становятся авторами контента — игра живёт дольше.
- Автор сразу видит, решаем ли уровень и насколько он сложный.
- Обмен уровнями превращает игру в платформу, а не только набор из 62 уровней.
- Хорошо сочетается с «уровнем дня» и мультиплеером.

## Эскиз реализации

1. **MVP в консоли:** уже есть `--author`; добавить проверку и экспорт.
2. **Локальный браузерный редактор:** форма + предпросмотр, без сервера.
3. **Обмен:** экспорт в JSON/код, импорт по коду.
4. **Галерея:** сервер, аккаунты, модерация (если нужно).

Формат `.lvl` остаётся источником истины; JSON — производный формат для web.

## Что затронет

`src/LevelGenerator.*` (или новый `src/Editor.*`), `web/` (UI редактора),
`data/levels/`, будущий `server/`, `docs/game.md`.

## Риски

- Модерация контента и спам.
- Совместимость форматов при развитии движка (нужна версия формата).
- Не каждый сгенерированный/нарисованный уровень интересен; нужны метрики
  качества и рейтинги.
- Нельзя усложнять `.lvl` так, чтобы консольная версия перестала его читать.
