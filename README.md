# func(math)

Игра-головоломка про числа и функции.

## Смысл игры

У вас есть **набор чисел** и **набор функций**. Каждая функция берёт два числа и
возвращает одно. Применив функцию к паре чисел, вы **убираете эти два числа из
набора и кладёте на их место результат**. Цель — получить в наборе заданное число.
Набор при этом постепенно «сжимается», поэтому важен порядок операций: это
головоломка на планирование последовательности.

Пример: набор `1 1`, функция `sum`, цель `2`. Вводим `sum 1 1` → оба числа
исчезают, в набор добавляется `2` — уровень пройден.

Особые механики:

- **Неизвестные функции.** Некоторые функции названы просто `A`, `B`, `C` — их
  поведение скрыто, и его нужно выяснить экспериментально (командой `calc`,
  которая считает, но не меняет набор).
- **Погрешность и случайность.** Функции `sumr/subr/mulr/divr` дают результат
  с погрешностью, `rand` возвращает случайное число. Такие уровни решаются
  «с запасом» или с нескольких попыток.
- **Откат и история.** `back` возвращает набор к состоянию до последнего хода,
  `reset` — к началу уровня, `history` показывает сделанные ходы. После каждого
  хода печатается текущий набор.

Выражения записываются без скобок и запятых: `func a b` (например `sum 1 3`).

Игра также помогает осваивать тему №19 ЕГЭ (теория чисел): остатки, делимость,
НОД/НОК, разложение на множители. Идеи развития в этом направлении — в
[`docs/ideas/`](docs/ideas/).

## Структура репозитория

| Путь | Что это |

| `src/` | исходники игры (C++17) |

## Быстрый старт

Сборка через g++ из корня репозитория:

```sh
g++ -std=c++17 -Wall -Wextra -O2 -o funcmath \
    src/Helper.cpp src/Functions.cpp src/Function.cpp src/LevelStore.cpp \
    src/Level.cpp src/Solver.cpp src/LevelGenerator.cpp src/Player.cpp \
    src/Game.cpp src/main.cpp
./funcmath
```

Или CMake:

```sh
cmake -S . -B build
cmake --build build
```

В Windows удобно `build.bat`. Запускать игру нужно из корня репозитория
(рядом с `data/`) или из каталога сборки, куда CMake копирует `data/`.

## Режимы командной строки

```sh
funcmath --check    # проверить все уровни на решаемость
funcmath --author   # создать новый уровень
```

Подробности о командах, формате `.lvl` и функциях — в
[`docs/game.md`](docs/game.md).
