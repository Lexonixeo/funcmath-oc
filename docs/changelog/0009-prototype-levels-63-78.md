# 0009. Уровни 63–78 из Java-прототипа

**Дата:** 2026-10-20

## Что сделано

- В `data/levels/` добавлены 16 уровней Java-прототипа `Lexonixeo/funcmath`
  как `level63.lvl`–`level78.lvl`:
  - 63–75 — `natural`;
  - 76–78 — `integer`.
- Порядок сохранён: прототипный уровень 1 → 63, …, 16 → 78. Числа, ответы и
  функции взяты из `*.dat`; старые 62 уровня не изменялись.
- Названия и авторские подсказки прототипа сохранены в
  `docs/prototype/levels.md`. В игре `hint` пока остаётся вычислительным:
  авторские тексты будут подключены отдельным шагом вместе с катсценами.
- Уровень 68 «Слепота» содержит 142 числа (133 восьмёрки). Чтобы решатель
  справлялся с такими мультимножествами:
  - состояния сортируются в каноническом порядке (большие числа первыми);
  - для арности 1–2 перебираются представители значений, а не все одинаковые
    экземпляры;
  - перед глубоким перебором выполняется проверка «цель одним ходом»;
  - стандартный лимит увеличен до 1 000 000 узлов.
  Благодаря этому уровень 68 решается за 2 хода, а не за сотни.
- Обновлены счётчики уровней в `README.md` и `docs/game.md`.

## Проверка

- `g++ -std=c++17 -Wall -Wextra -O2` — без ошибок.
- `cmake --build build` — без ошибок.
- `--check` по всем 78 уровням:
  **решаемо 77, не найдено 1, со случайностью 7, с ошибками 0**.
  Не найден только старый уровень 18 (известное ограничение DFS); все 16 новых
  уровней решаются, включая 68 (2 хода) и 71 (`primes`).
- Вручную проверены:
  - уровень 63: `sum 1 1`;
  - уровень 71: `primes 30`, `primes 77`, `mul 3 mul 7 11`;
  - `calc mul primes 77` на уровне 71 печатает `77`;
  - уровень 68: `sum 9 8`, затем `sum 17 6` даёт 23.
- Проверено, что один вложенный вызов с несколькими результатами заполняет
  несколько аргументов родителя (`mul primes 77`).
