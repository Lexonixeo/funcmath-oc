# 0017. Аудит уровней, справка и текстовые релизные документы

**Дата:** 2026-10-22

## Что сделано

- Убран обязательный вопрос «оцените сложность уровня» после прохождения.
  Вместе с ним удалена средняя оценка из `stats`; `data/lvlrate.dat` больше не
  используется.
- Обучение при первом уровне стало коротким, но достаточным: что делает
  функция, как забираются числа, префикс и инфикс, `calc`, `back`, `reset`.
- `help` внутри уровня стал подробнее: команды, примеры, `exit` в главное
  меню, пояснение `natural`/`integer` и typed-литералов. `help` можно вызвать
  после `clear`.
- В релизные архивы добавляются `README.txt` и `docs/*.txt`. Исходники в
  репозитории остаются в Markdown; преобразование делает
  `tools/md_to_txt.py` при конфигурации CMake.
- Проведён аудит уровней, результат — `docs/level-audit.md`. Удалены дубли
  63–78, шумовые `subr`/`mulr`/`divr`, `neg2`/`five` и зависимые уровни;
  уровни с этими функциями восстановлены с функциями внутри уровня.
  Сохранены `sumr` (уровень 47) и чистый `rand` (уровень 46).
- `abs` и `not` стали унарными; уровни 21 и 40 переписаны.
- `avg` и `sumr` задаются в уровнях как пользовательские функции; `neg2`,
  `five`, `subr`, `mulr` — тоже (восстановленные уровни).
- 72 уровня переставлены в новый курсовый порядок, таблица старых и новых
  номеров — `docs/level-renumbering.md`. Прогресс игроков при обновлении
  сбрасывается.
- Добавлена лицензия MIT (`LICENSE`), SPDX-заголовки в исходниках.
- CTest снова проверяет уровень 18, но с отдельным увеличенным лимитом.
  `FM_KNOWN_UNSOLVABLE_LEVELS` пуст.
- Генератор случайных уровней поддерживает унарные функции, а не только
  бинарные.

## Зачем

Уровни накапливались из трёх прототипов: часть была дублями, часть держалась
на одноразовых функциях, а некоторые задачи решались только перебором. Игроку
нужен короткий старт и понятная справка, а релизному архиву — документация,
которую можно открыть без Markdown-просмотрщика.

## Проверки

- `funcmath --check` с обычным лимитом: 71 из 72, не найден только уровень 18.
- `funcmath --check 18 --nodes 50000000 --time 60000`: решается.
- `ctest --test-dir build -C Release --output-on-failure`: все тесты проходят.
- `cmake --build build --target package --config Release`: в архиве есть
  `README.txt` и `docs/*.txt`.
- Проверено, что в уровнях и `data/functions.txt` не осталось ссылок на
  удалённые функции.

## Затронутые файлы

- `src/Game.*`, `src/Level.cpp` — удаление рейтинга, обучение и `help`;
- `src/Functions.*`, `src/LevelGenerator.cpp` — унарные `abs`/`not`, удаление
  шумовых функций, генерация с произвольной арностью;
- `data/levels/`, `data/functions.txt` — чистка и перенумерация;
- `CMakeLists.txt`, `tools/md_to_txt.py` — текстовые документы для релиза;
- `README.md`, `AGENTS.md`, `docs/*.md` — актуализация;
- `docs/level-audit.md`, `docs/level-renumbering.md` — результаты аудита.
